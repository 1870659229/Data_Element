摘    要:［目的］为了提升复杂航行环境下智能船舶的自主路径规划能力，提出一种自适应方向限制A*算
法。［方法］首先，对海图环境进行预处理，提取障碍物边界并进行双层膨化，使船舶与障碍物保持安全距
离。然后，改进A*算法的节点搜索策略，使其在路径规划过程中可根据终点自适应地调整搜索节点的方向与
数量，提高算法的运行效率。最后，优化路径的安全检测方式，提取关键路径点，提高路径的安全性与平滑
性。［结果］实验数据显示，相比于A*算法、Bi-A*算法、ERA*算法和RRT*算法，ADR-A*算法路径长度减少
3.56%，运行时间优化60.13%，转向点数减少76.71%。［结论］算法可以在复杂环境下规划出兼具安全性、经
济性与平滑性的可航路径，验证了ADR-A*算法的自主路径规划能力，为智能船舶自主航线设计提供优化的
解决方案与安全保障。

0    引　言
随着全球贸易的持续增长、科技的迅猛进步
以及对环境保护意识的不断提升，智能船舶作为
航运业数字化转型的重要载体，正逐渐进入工程
应用阶段。路径规划
[1,2] 作为其核心要素之一，旨
在通过先进的算法与技术手段，为船舶在复杂的
海洋环境中规划出安全、高效且经济的航行路
径。众多学者使用智能路径规划算法
[3,4] 生成优
化航线，常见的路径规划方法有智能算法、随机
采样算法、图形搜索算法和局部优化算法等。
A*算法（adaptive direction restriction-A*, ADR-
A*）
[5] 作为一种经典的图形搜索算法，因其计算原
理简单，使用方便等优点得到广泛应用。但在大
规模的复杂环境中进行路径规划时，A*算法存在
往返搜索、内存开销大、搜索效率差以及搜索节
点冗余等问题。为解决上述问题，Ammar
[6] 创新
性地提出了增强型松弛A*算法（enhanced relaxed
A*, ERA*），提出了查找矩阵的新颖计算策略。
仿真实验证明，ERA*算法显著减少了冗余计算，节
省了大量时间和内存。Li 等
[7] 在A*算法中引入双
向交替搜索策略，同时采用滤波函数和贝塞尔曲线
减小转弯角度和路径长度，提高了搜索效率和路径
平滑度。王敏等
[8] 通过同步双向搜索策略和动态权
重调整方法，减少了路径冗余点和算法计算时间。
胡明哲等
[9] 对启发函数的权重值进行调整，将启
发函数作为底数进行指数运算，缩短了算法搜索
时间，并通过仿真实验验证了该方法的有效性。
为进一步提高算法的运行效率，减少冗余节
点数量，部分学者对A*算法的节点搜索方式进行
优化。姚得鑫等
[10] 提出了一种24 邻域搜索策略
与角度搜索法相结合的新策略，减少了路径搜索
过程中的非必要节点，提高了搜索节点的质量，
使搜索过程更具有目标导向性。Wang 等
[11] 将

[14] 通过
改进Hybrid A*算法中的启发式函数，减少了节点
搜索数量；通过构建安全走廊，增加了路径与障
碍物的距离。Lü等
[15] 将传统A*算法的8 邻域搜
索策略改进为动态14 邻域搜索策略，有效地减少
了路径上的拐点数量。同时，根据实际环境定义
相关阈值，以此保证路径规划的可达性，提高了
路径的可用性和安全性。Song 等
[16] 提出碰撞风
险函数，以增强A*算法的启发式功能。经优化
的A*算法可根据路径长度和碰撞风险规划最优
路径，有效提高了规划路径的整体质量，但算法
整体运行时间较长。
通过以上的文献综述发现，目前的研究主要
针对A*算法的单一不足进行优化，缺少可规划出
兼顾安全性、经济性、高效性与平滑性的综合型
可航路径的算法，且仿真实验环境较为简单，无
法充分体现算法在复杂环境中的路径规划能力。
在智能船舶产业化过程中迫切需要一种在复杂的
海图环境中生成综合型可航路径的方法。基于
此，本文将提出一种ADR-A*算法，以实现并优化
智能船舶离线路径规划功能。首先，提出自定义
双层边界膨化策略，对海图环境进行预处理，在
保留岛礁环境特征的同时，提高路径的安全性。
其次，对A*算法的节点搜索方式进行优化，创新
性地提出自适应方向限制优先节点搜索策略，使
算法可以在寻路过程中自适应地调整搜索节点的
位置与数量，提高算法的搜索效率。最后，基于
路径全覆盖策略剔除冗余节点，显著提高路径的
经济性与平滑性。本文旨在通过以上3 种策略优
化A*算法，为智能船舶在复杂海洋环境中的路径
规划提供新的解决方案。
 
1    路径规划算法
 
1.1    传统A*算法
A*算法是一种经典的启发式搜索算法，常用
于静态路网中求解最短路径问题。A*算法的评
价函数为

A*算法在运算过程中需建立open-list 和
close-list 两个列表。其中open-list 用于储存待检
测的节点，close-list 用于储存已检测的节点。算
法首先从open-list 中选取具有最小评价函数值的
节点作为当前节点，并将其移入close-list；然后，
算法搜索相邻节点，将其中非障碍物且未被收录
于close-list 的子节点加入open-list，并计算其相应
的评价函数值。该过程通过迭代更新open-list 中
的节点信息，并依据评价函数值重新选择当前节
点进行搜索，直至搜索到终点为止。

束条件，即剔除与终点方向相关性较低的相邻节

有良好的适航性。同时，本文将真实海图距离与

Abstract: ［Objectives］In order to improve the autonomous path planning ability of intelligent ships under
complex navigation environment, and to improve the traditional A* algorithm's problem of planning paths in
complex obstacle environments with many nodes and close distances to obstacles, an Adaptive Direction Re-
striction-A* (ADR-A*) algorithm is proposed. ［Methods］Firstly, a Customizable Double-layer Boundary
Expansion Strategy (CDBES) is proposed, which preprocesses the chart environment by extracting the obsta-
cle boundaries, and generates the first-layer expanded chart and the second-layer expanded chart. The algo-
rithm generates initial paths outside the second-layer expanded chart and eliminates redundant nodes outside
the first-layer expanded chart. By customizing the buffer zone and warning zone, CDBES enables the plan-
ning algorithm to adjust the distance of the path points away from the obstacle boundary on demand while con-
sidering the real boundary characteristics of the obstacle, and provides a solution space for optimizing the path
to eliminate redundant nodes, which lays a solid foundation for the overall path planning process. Secondly,
the node search method of A* algorithm is improved, and the Adaptive Direction Restriction Priority-node
Search Strategy (ADRPSS) is innovatively proposed. This strategy defines the neighboring nodes as second-
priority nodes and priority nodes, improves the quality of search nodes by traversing the priority nodes, and
further improves the search speed by eliminating search nodes with low relevance according to the endpoint
position. ADRPSS can adaptively update the position and number of search nodes according to the informa-
tion of the chart obstacles and the endpoint position, which strengthens the goal-directedness of the algorithm,
and significantly enhances the efficiency of the path planning. Finally, a new Path Full Coverage Strategy
(PFCS) is proposed to improve the path smoothness. This strategy treats the path as a region with a certain
width instead of a single line, and conducts collision detection based on it to eliminate dangerous points and re-
dundant nodes, which results in a more comprehensive algorithmic safety assessment, fewer retained nodes,
and smoother paths. ［Results］The experimental data show that compared with the A* algorithm, Bi-A* al-
gorithm, ERA* algorithm and RRT* algorithm, in chart I, the ADR-A* algorithm reduces the path length by
3.56%, optimizes the running time by 60.13% and reduces the number of steering points by 76.71%. In chart
II, the ADR-A* algorithm reduces the path length by 3.36%, optimizes the running time by 11.16%, and re-
duces the number of steering points by 53.85%. ［Conclusions］The experimental results show that the algo-
