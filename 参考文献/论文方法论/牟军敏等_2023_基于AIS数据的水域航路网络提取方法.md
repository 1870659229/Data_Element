## 一、研究背景与问题

### 1.1 研究背景
随着国际航运重心东移，核心港区的蓬勃发展为船舶交通安全管理带来巨大压力。船舶自动识别系统(AIS)作为现代助航信息系统，已广泛应用于海事监管、交通流分析等领域。

### 1.2 现有方法的局限性
现有AIS航路提取方法主要分为三类：

| 方法类型 | 代表性工作 | 局限性 |
|---------|-----------|--------|
| **空间划分** | 牛敬华等[3], FILIPAK等[4] | 均匀网格导致冗余计算；不均匀划分增加复杂性 |
| **聚类方法** | YAN等[6], 肖潇等[7] | 对空间密度分布差异大的数据集效果不理想 |
| **图像处理** | LEE等[9], KONDO等[10] | 泛化能力差、适应性弱、算力成本高 |

### 1.3 核心研究问题
现有研究存在两个主要缺陷：
1. **多集中于局部航路提取**，忽略了水域的航路网络特征
2. **缺乏对具体航路范围的清晰认识**

### 1.4 解决思路
立足于AIS大数据，通过挖掘船舶轨迹特征，构建**从局部航路特征到全局航路网络的一体化模型**。

## 二、方法论框架

### 2.1 技术路线（四模块模型）

```
┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐
│ AIS数据预处理   │ → │ 轨迹特征识别   │ → │ 网络拓扑构建   │ → │ 航路生成       │
│                 │    │                 │    │                 │    │                 │
│ • 数据解码重构  │    │ • 静止点识别   │    │ • 节点提取     │    │ • 中心线提取   │
│ • 异常数据清洗  │    │ • 转向点识别   │    │ • 边提取       │    │ • 范围确定     │
└─────────────────┘    └─────────────────┘    └─────────────────┘    └─────────────────┘
```

### 2.2 船舶航行状态分类
通常船舶在航行时的状态可分为三种：
- **直航状态**：正常航行，无特殊特征
- **静止状态**：速度接近0的关键特征
- **转向状态**：航向变化的关键特征

**核心假设**：同一条航路中的船舶轨迹具有高度相似的移动趋势和运动特征

## 三、AIS数据预处理模块

### 3.1 数据规范
按照国际电工委员会(IEC)和国际电信联盟(ITU)制定的规范[11-12]对原始AIS数据进行解码和重构。

### 3.2 异常数据清洗
基于GUO等[13-14]提出的方法对异常数据进行清洗。

### 3.3 轨迹数据结构定义

设重构后的轨迹数据集为：
$$TS = \{T_i\}_{i=1,2,...,n}$$

其中包含n条轨迹，第i条轨迹定义为：
$$T_i = \{p_{i,j}\}_{j=1,2,...,m}$$

m为$T_i$所包含的轨迹点数目，每个轨迹点定义为：
$$p_{i,j} = (p_{mmsi}, t, p_{long}, p_{lat}, v_{sog}, c_{cog}, h_{heading})$$

字段含义：
- $p_{mmsi}$: 水上移动通信业务标识码(MMSI)
- $t$: 时间戳
- $p_{long}$: 经度
- $p_{lat}$: 纬度
- $v_{sog}$: 对地航速(SOG)
- $c_{cog}$: 对地航向(COG)
- $h_{heading}$: 艏向

## 四、轨迹特征识别模块

### 4.1 静止点识别

#### 识别原理
当船舶静止时，其航速为0或接近于0。

#### 判定条件
对于$T_i$中的轨迹点$p_{i,j}$，当满足以下条件时，定义$p_{i,j}$为静止点：

$$
\begin{cases}
v_{i,j} < 0.5 \\
\frac{v_{i,j} - v_{i,j-1}}{t_{i,j} - t_{i,j-1}} < 0.2 \\
\frac{v_{i,j+1} - v_{i,j}}{t_{i,j+1} - t_{i,j}} < 0.2
\end{cases}
\quad (1)
$$

式中：
- $v_{i,j}$: 第i条轨迹中第j个数据点的速度 (单位: kn)
- $t_{i,j}$: 点$p_{i,j}$对应的时刻
- **速度阈值**: < 0.5 kn
- **加速度阈值**: < 0.2 kn/s

#### 参数说明
- **速度阈值0.5 kn**: 用于识别基本静止状态
- **加速度阈值0.2 kn/s**: 排除短暂停顿或低速航行的情况

### 4.2 转向点识别

#### 识别难点
虽然AIS数据中包含航向数据，但由于：
- 数据质量无法保证
- AIS报告频率经常变化

导致AIS数据中的航向角信息难以体现船舶的转向特征。

#### 解决方案：DP(Douglas-Peucker)轨迹压缩算法

#### 算法原理
DP算法是一种经典的曲线简化算法，通过递归方式识别轨迹中的关键转折点。

#### 算法流程（如图2所示）
1. **输入**: 原始轨迹序列和距离阈值$d_{max}$
2. **步骤1**: 连接轨迹首尾两点形成线段
3. **步骤2**: 计算所有中间点到该线段的垂直距离
4. **步骤3**: 找出最大距离点
5. **判定**:
   - 若$d_{max} < d_{max}$: 该点为转向点，递归处理两段子轨迹
   - 若$d_{max} \leq d_{max}$: 该段轨迹可用线段近似，无需进一步分割
6. **输出**: 轨迹中的所有转向点集合

#### 关键参数
- **距离阈值$d_{max}$**: 决定转向点的敏感度
  - 实例分析中使用: **2 km**（根据水域尺度设定）

#### 算法优势
- 能够有效识别显著的航向变化点
- 对噪声具有一定的鲁棒性
- 计算效率较高

## 五、网络拓扑构建模块

### 5.1 特征区识别（节点提取）

#### 5.1.1 DBSCAN密度聚类

##### 算法选择理由
DBSCAN(Density-Based Spatial Clustering of Applications with Noise)[15]能够：
- 从点集中筛选出低密度区域和高密度区域
- 将低密度区域作为噪声进行过滤
- 无需预先指定聚类数目
- 能够发现任意形状的簇

##### 聚类过程

对于任意轨迹点$p_i \in P_S$（静止点集合）或$p_i \in P_T$（转向点集合）：

**Step 1**: 求$\varepsilon$邻域$N_\varepsilon(p_i)$及其内点的个数$|N_\varepsilon(p_i)|$

**Step 2**: 点类型判定

$$
\text{若 } |N_\varepsilon(p_i)| \geq P_{min}:
\begin{cases}
p_i \text{ 为核心点} \\
\text{继续寻找邻域内的其他核心点} \\
\text{直到没有核心点为止}
\end{cases}
$$

$$
\text{若 } |N_\varepsilon(p_i)| < P_{min}:
\begin{cases}
\text{邻域内存在核心点} \Rightarrow p_i \text{ 为边界点} \\
\text{邻域内无核心点} \Rightarrow p_i \text{ 为噪声点}
\end{cases}
$$

**Step 3**: 构建特征区
- 所有核心点与其邻域范围内的所有点构成一个**特征区**

##### 聚类结果
- **静止点集合$P_S$** → 静止区集合 $AS = \{A_i\}_{i=1,2,...,A}$
  - A为静止区个数
  - 第i个静止区: $A_i = \{p_{i,j}\}_{j=1,2,...,A_i}$

- **转向点集合$P_T$** → 转向区集合 $BT = \{B_i\}_{i=1,2,...,B}$
  - B为转向区个数
  - 结构同理

##### 关键参数（实例分析）
- $\varepsilon$ (邻域半径): **250 m**
- $P_{min}$ (簇内最小点数): **30**

#### 5.1.2 AS(Alpha Shapes)边界提取

##### 算法选择理由
Alpha Shapes算法[16]能够：
- 快速、简单地从离散空间点集中提取边界轮廓
- 有效应对点集中的空洞、断裂、凹陷等情况
- 通过参数$\alpha$控制边界的精细程度

##### 算法原理
类似用一个半径为$\alpha$的圆不断在点集上进行滚动的方法来发现边界。

##### 边界点判定规则
以静止区$A_i$为例，对于其中的任意两点$a_{i,j}$和$a_{i,k}$：

**条件**: 当$d(a_{i,j}, a_{i,k}) \leq 2\alpha$时

**操作**:
1. 过这两点绘制两个半径为$\alpha$的圆
2. **判定规则**: 当至少有一个圆不包含$A_i$中的其他点时
3. **结论**: $a_{i,j}$和$a_{i,k}$为**边界点**

##### 输出结果
- 建立边界点集合$A_{边界}$与$A_i$进行关联
- 转向区同理处理

##### 关键参数（实例分析）
- $\alpha$: **$10^5$**（避免空洞、断裂、凹陷）

### 5.2 节点定义

每个特征区可视作水域航路网络拓扑中的一个**节点**：
- **静止区节点**: 代表船舶停泊/锚泊区域
- **转向区节点**: 代表船舶频繁转向的位置

### 5.3 边提取（频繁轨迹模式识别）

#### 5.3.1 轨迹划分

利用节点对轨迹进行划分（如图5所示）：

假设有一条轨迹$T_i$经过k个节点，可将其划分为k-1段子轨迹：
$$T_i\text{-sub} = \{T_1, T_2, ..., T_{k-1}\}$$

每段子轨迹代表从一个节点到另一个节点的路径。

**示例**: 如图5所示，轨迹被划分为4段子轨迹$T_1, T_2, T_3, T_4$

#### 5.3.2 频繁模式判定

对于节点M和节点N（如图6所示）：

**输入参数**:
- 频繁模式阈值: f

**算法流程**:
1. 初始化计数器: $c = 0$
2. 遍历所有轨迹的$T_i\text{-sub}$
3. 对于每个子轨迹段:
   - **若**起始节点=M **且**终止节点=N:
   - 则: $c = c + 1$
4. **判定**:
   - **若** $c > f$: 存在从M到N的**频繁轨迹模式** → 建立**有向边**
   - **若** $c \leq f$: 不建立边

#### 5.3.3 网络拓扑构建

对所有节点进行两两频繁轨迹模式判断，最终得到：
- **节点集合V**: 所有特征区（静止区∪转向区）
- **边集合E**: 所有频繁轨迹模式对应的有向边
- **有向图G = (V, E)**: 水域航路网络拓扑

##### 关键参数（实例分析）
- **频繁模式阈值f**: 取所有节点间轨迹数目的**99分位数**

##### 双向航道合并
当同一对节点间存在两个方向的航路时，对其进行合并以对应实际的双向航道（如图14d所示）

## 六、航路生成模块

### 6.1 中心线提取（DTW算法）

#### 6.1.1 问题背景
节点间的轨迹具有不同的长度和轨迹点数目，需要解决轨迹长度不匹配的问题以提取代表性航路中心线。

#### 6.1.2 DTW(Dynamic Time Warping)算法原理[17-18]

DTW是一种用于度量两个时间序列相似性的算法，能够处理不同长度的序列。

#### 6.1.3 相似度计算

对于两段轨迹序列$T_1$和$T_2$，其相似度矩阵D的计算公式：

$$D(i,j) = d_{ij} + \min\{D(i,j-1), D(i-1,j), D(i-1,j-1)\} \quad (2)$$

式中：
- $d_{ij}$: $T_1$中第i个点与$T_2$中第j个点之间的欧氏距离
- **边界条件**: 从$D(1,1)$开始计算至$D(m,n)$
- **最终相似度**: $f_{DTW}(T_1, T_2) = D(m,n)$

#### 6.1.4 匹配路径记录

在计算过程中，建立匹配索引集$Z = \emptyset$：

**操作规则**:
- 每次选择一个D值时，将对应的索引值添加进Z
- **示例**: 选择$D(i-1,j)$时，向Z中添加索引值$(i-1, j)$
- 计算完成后，Z记录了每次匹配所选的$T_1$和$T_2$中的轨迹点

#### 6.1.5 中心点计算

从$(1,1)$开始按顺序从Z中选择索引值，设第k次的索引值为$(i, j)$：

则位于$p_{1,i}$和$p_{2,j}$两点连线中点的**中心线轨迹点**为：

$$C_k = \frac{p_{1,i} + p_{2,j}}{2} \quad (3)$$

得到的当前中心线：
$$L_{centerline} = \{C_1, C_2, ..., C_{|Z|}\}$$

$|Z|$为索引集中元素的个数。

#### 6.1.6 迭代优化

**迭代流程**:
1. 得到初始中心线$L_{centerline}$
2. 将其作为新的$T_1$
3. 从轨迹集中选择一条未选择过的轨迹作为新的$T_2$
4. 继续执行上述DTW计算过程
5. **终止条件**: 轨迹集中的所有轨迹都被选择过
6. **输出**: 最终的中心线$L_{centerline}$

### 6.2 航路范围确定（垂线分治法）

#### 6.2.1 方法动机
为了自动确定节点间航路的具体范围（宽度），提出垂线分治法。

#### 6.2.2 算法输入
- 节点M和N（存在从M到N的频繁轨迹模式）
- 提取的中心线$L_{centerline}$
- M和N之间的所有轨迹点集合

#### 6.2.3 算法步骤

**Step 1: 中心线分段**

将中心线$L_{centerline}$分段为子轨迹段：
$$C_1C_2, C_2C_3, ..., C_{L_{centerline}-1}C_{L_{centerline}}$$

$L_{centerline}$为中心点的个数（如图8所示）

**Step 2: 垂线距离计算**

对于每个子轨迹段$C_iC_{i+1}$（如图9所示）：

1. 过所有轨迹点向线段$C_iC_{i+1}$作垂线
2. **过滤**: 舍去垂足不在$C_iC_{i+1}$线段上的轨迹点
3. 计算剩余各点到中心线的**垂直距离**
4. 将距离值记入集合$D$

**Step 3: 宽度阈值确定**

1. 将D中的距离值按从小到大排序
2. 取**阈值分位数**对应的距离宽度作为**航路宽度**
3. 构建**子航路段**（如图10所示）:
   - 长: $C_iC_{i+1}$的长度
   - 宽: 确定的距离宽度

**Step 4: 相邻路段合并**

对于两个相邻的子航路段（如图11所示），以轨迹方向为参考，交界处四个点的合并规则：

$$
\begin{aligned}
P_{left} &= \frac{p_{i,left} + p_{i+1,left}}{2} \\
P_{right} &= \frac{p_{i,right} + p_{i+1,right}}{2}
\end{aligned}
\quad (4)
$$

式中：
- $P_{left}, P_{right}$: 分别表示航路的左右侧范围
- $p_{i,left} + p_{i+1,left}$: 两个相邻子航路段位于轨迹左侧的数据点
- $p_{i,right} + p_{i+1,right}$: 位于轨迹右侧的数据点

**Step 5: 最终航道生成**

将所有子航路段交界处的点进行合并，得到**最终航道多边形**。

## 七、算法复杂度分析

### 7.1 各模块时间复杂度

| 模块 | 主要算法 | 时间复杂度 | 说明 |
|------|---------|-----------|------|
| AIS预处理 | 数据清洗 | O(n) | n为轨迹点数量 |
| 特征识别 | DP算法 | O(n log n) | n为单条轨迹点数 |
| 节点提取 | DBSCAN | O(n log n) | n为特征点总数 |
| 边界提取 | Alpha Shapes | O(n log n) | n为特征区内点数 |
| 边提取 | 频繁模式统计 | O(m × k²) | m为轨迹数，k为节点数 |
| 中心线提取 | DTW | O(n²) | n为轨迹点平均数 |
| 范围确定 | 垂线分治 | O(n × l) | n为轨迹点数，l为中心线段数 |

### 7.2 空间复杂度
- 总体空间复杂度: O(n + m × k)
- 主要存储需求: 轨迹数据、特征点、网络拓扑结构

## 十、方法适用性与局限性

### 10.1 适用场景

✅ **适用于**:
- 大中型港口及附近水域
- 船舶交通流量较大的区域
- 需要掌握航路网络结构的监管场景
- 习惯航路发现与监测

### 10.2 局限性

⚠️ **局限性**:
1. **参数敏感性**: DBSCAN的$\varepsilon$和$P_{min}$需根据具体水域调整
2. **计算开销**: DTW算法在大规模轨迹数据上计算量较大
3. **依赖数据质量**: AIS数据的完整性和准确性影响结果
4. **静态快照**: 单一时间段的提取无法体现时变特性
5. **阈值设定**: 频繁模式阈值f的选择缺乏理论指导

### 10.3 改进方向

1. **参数自适应**: 研究参数自动优化方法
2. **算法加速**: 引入并行计算或近似DTW算法
3. **时序建模**: 扩展为时空航路网络演化模型
4. **多源融合**: 结合电子海图、雷达等多源数据
5. **深度学习**: 探索端到端的航路网络提取方法
