## 核心方法论 ⭐⭐⭐ 与本项目GAT高度相关

### 一、问题定义
**船舶轨迹预测**: 基于历史AIS数据，预测船舶未来位置轨迹。
核心挑战：
1. 船舶间的空间交互（避让、会遇）
2. 轨迹的时序依赖（惯性、转向模式）
3. 传统方法无法同时建模时空特征

### 二、GAT-LSTM混合模型架构（4层）

```
┌─────────────────────────────────────────────────────┐
│  Input Layer: AIS dataset → Data Preprocessing      │
│  → 构建Vessel Network Graph (船舶网络图)              │
├─────────────────────────────────────────────────────┤
│  GAT Layer: Spatial Relationship                     │
│  → 提取船舶间空间交互特征                              │
│  → 多头注意力机制 (Multi-head Attention)              │
├─────────────────────────────────────────────────────┤
│  LSTM Layer: Temporal Correlation                    │
│  → 提取单船轨迹的时序特征                              │
│  → 门控机制捕获长期依赖                                │
├─────────────────────────────────────────────────────┤
│  Output Layer: Vessel Trajectory Prediction          │
│  → 输出未来时刻的 (LAT, LON) 坐标                      │
└─────────────────────────────────────────────────────┘
```

### 三、关键技术细节

#### 3.1 船舶网络图构建 (Vessel Network Graph)
- **节点(V)**: 每艘船舶为一个节点
- **边(E)**: 两船距离 ≤ 5 nautical miles 时建立连接
- **邻接矩阵A**: N×N对称矩阵，元素为距离倒数权重
  ```
  A'[i,j] = { 1/d'_i,j, if d'_i,j ≤ 5 n miles
            { 0, otherwise
  ```
- **归一化**: Â = (D')^(-1/2) × Ã × (D')^(-1/2)
- **自环**: Ã = A' + I （加入自身连接）

#### 3.2 GAT层 - 空间特征提取
**注意力系数计算**:
```
e_ij = LeakyReLU(a^T [W h_i || W h_j])
α_ij = softmax(e_ij) / Σ_k exp(e_ik)
```
**节点特征更新**:
```
h'_i = σ(Σ_{j∈N(i)} α_ij · W h_j)
```
**多头注意力增强** (K=3):
```
h''_i = ||_{k=1}^{K} (Σ_j α^k_ij · W^k h_j)
```

#### 3.3 LSTM层 - 时序特征提取
标准LSTM门控单元:
- **输入门**: i_t = σ(W_xi·x_t + W_hi·h_{t-1} + b_i)
- **遗忘门**: f_t = σ(W_xf·x_t + W_hf·h_{t-1} + b_f)
- **输出门**: o_t = σ(W_xo·x_t + W_ho·h_{t-1} + b_o)
- **候选记忆**: g_t = tanh(W_xc·x_t + W hc·h_{t-1} + b_c)
- **细胞状态**: c_t = f_t * c_{t-1} + i_t * g_t
- **隐藏状态**: h_t = o_t * tanh(c_t)

### 四、实验设置

| 项目 | 设置 |
|------|------|

| 时间范围 | 2020年8月1日 ~ 10月31日 |
| 输入特征 | LAT, LON, SOG, COG |
| 预测目标 | 未来时刻的 LAT, LON |
| 对比基线 | LSTM, CNN-LSTM, GRU, Seq2seq |

### 五、实验结果 ⭐

| 模型 | MAE | RMSE | ADE | FDE |
|------|-----|------|-----|-----|
| LSTM | 较高 | 较高 | - | - |
| CNN-LSTM | 中等 | 中等 | - | - |
| GRU | 中等 | 中等 | - | - |
| Seq2seq | 较低 | 较低 | - | - |
| **GAT-LSTM** | **最低** | **最低** | **最优** | **最优** |

**关键发现**:
1. GAT-LSTM在直线航段各模型表现接近
2. **转弯场景下GAT-LSTM显著优于所有基线** —— 因为能捕捉空间交互
3. 狭窄航道转弯后，GAT-LSTM预测最贴近真实值
4. 平均位移误差降低 **44.52%**, 最终位移误差降低 **55.20%**

### 六、场景分析（6种典型场景）

| 场景 | GAT-LSTM表现 | 基线模型表现 |
|------|-------------|-------------|
| (a) 直线航行 | 各模型均好 | 各模型均好 |
| (b) 直线返航 | 各模型均好 | 各模型均好 |
| (c) 直行后快速转弯 | **贴近真实** | LSTM/CNN-LSTM偏离大 |
| (d) 转弯后快速返回 | **方向+位置准确** | 基线偏离趋势 |
| (e) 驶向锚地减速 | **间距递减正确** | 基线未体现减速 |
| (f) 狭窄航道转弯后 | **最接近真实值** | 所有基线偏离 |

### 八、对本项目的具体借鉴价值

1. **GAT注意力机制实现参考**:
   - 注意力系数: `LeakyReLU(a^T[Wh_i||Wh_j])` + softmax归一化
   - 多头注意力(K=3)提升表达能力
   - 对称归一化邻接矩阵: `(D^-1/2)AD(D^-1/2)`

2. **邻接矩阵构建策略**:
   - 距离阈值法（≤5nm）→ 本项目可用距离/角度阈值构建航道连接
   - 权重为距离倒数 → 本项目可用历史AIS流量或平均速度作为权重

3. **损失函数设计**: 文章使用MSE损失，本项目可考虑加权MSE（高峰时段样本权重更高）

4. **特征工程**: LAT/LON/SOG/COG 四维基础特征可作为本项目节点特征的基准
