# 考虑交通轨迹密度的船舶路径规划方法

**作者**: 张策, 刘钊, 张明阳, 罗辰汉, 刘康  
**来源**: 中国航海, 2025, 48(增刊1): 72-79  
**DOI**: 10.3969/j.issn.1000-4653.2025.S1.011

---

## 一、研究背景与问题

### 1.1 研究背景
- 全球海上贸易快速增长，海上安全事故备受关注
- 船舶自动识别系统（AIS）数据的海量累积，使海上交通数据利用成为研究热点
- 在交通繁忙水域，考虑交通轨迹密度进行船舶路径规划可保障航行安全性和通航高效性

### 1.2 存在的问题
- 现有船舶路径规划多数仅关注自然环境因素
- 未充分考虑船舶交通条件
- 船舶路径规划与实际船舶交通轨迹特征差异性大
- 降低了船舶规划路径的实用性

## 二、方法论框架

### 2.1 整体流程
```
输入: AIS数据 + 电子海图
    ↓
步骤1: 构建轨迹密度关联特征的水域栅格环境
    ↓
步骤2: 计算船舶轨迹密度
    ↓
步骤3: 改进A*算法（引入奖惩函数+扩展节点）
    ↓
输出: 最优路径
```

## 三、核心方法详解

### 3.1 轨迹密度关联特征的水域栅格环境建模

#### 3.1.1 水域栅格化

**1) 栅格尺度设置**
- 采用正方形方格对水域进行栅格化
- 栅格长度应不小于 **2倍的最小安全距离**
- 栅格尺度与精度的权衡：
  - 尺度越大 → 特征地图描述越粗糙，规划路径质量越差，误差越大
  - 尺度越小 → 环境碍航物描述越精确，规划路径质量越好，但计算速度变慢

**2) 栅格编码**
- 对 M×N 个栅格构成的栅格地图
- 从左上角开始，按从左到右、从上到下的顺序自1开始编号

**3) 可航栅格确定**
- 满足船舶安全航行需求的栅格为可航栅格
- 不可航栅格：存在不可航区域的栅格
- 对有不可航区域的栅格进行**膨胀处理**

#### 3.1.2 栅格交通轨迹密度计算

**基本规则：**
- 每有1条船舶轨迹穿越栅格内部，则计数1次

**特殊情况处理：**

| 情况 | 处理方式 |
|------|----------|
| 船舶轨迹和栅格边界重合 | 轨迹两侧的栅格各计数 **0.5** |
| 船舶轨迹通过栅格线十字交会处 | 对角线两侧的栅格各计数 **0.5** |

**轨迹密度归一化（公式1）：**
```
x_i,norm = ln(x_i) / ln(x_max)
```
其中：
- `x_i,norm`: 标准化后的第i个栅格的密度值
- `x_i`: 第i个栅格内的轨迹数（条）
- `x_max`: 最大轨迹数量栅格的轨迹数（条）

**归一化目的：**
- 解决不同时间尺度下交通轨迹数量的差异性
- 提升栅格交通环境在路径规划中使用的方便性
- 使轨迹密度值与其他栅格环境值相匹配

### 3.2 改进A*算法

#### 3.2.1 A*算法基础

**核心启发函数（公式2）：**
```
f(n) = g(n) + h(n)
```
其中：
- `f(n)`: 起点到点n的路径成本
- `g(n)`: 起点到点n的实际成本
- `h(n)`: 从点n到目标点的成本估计值

#### 3.2.2 节点扩展方法

**邻域扩展策略：**

| 邻域类型 | 可移动方向 | 说明 |
|----------|------------|------|
| 4邻域 | 上、下、左、右 | 基础版本，路径与实际运动轨迹差距较大 |
| 8邻域 | 4邻域 + 左上、左下、右上、右下 | 扩展对角方向 |
| K层扩展 | 更多方向 | 进一步扩展邻域节点 |

**K层扩展公式：**
```
可移动方向 D_K = 8 × [1 + K(K-1)/2],  K≥1; K∈Z     (公式3)

邻域数量 N_K = 8 × K(K+1)/2,  K≥1; K∈Z              (公式4)
```

**K值选取原则：**
- 综合考虑运动对象的操作性能限制
- 考虑对算法效率的需求
- 本文最终选择 **24个邻域节点**

#### 3.2.3 引入奖惩因素函数

**设计思想（基于人工势场理论）：**
- 轨迹密度较高区域 → 对船舶形成**吸引力**（奖励）
- 障碍物/不可通航水域 → 对船舶形成**排斥力**（惩罚）

##### (1) 奖励因素函数

**目标点奖励函数（公式5）：**
```
U_att(q) = (1/2) × η × ρ²(q, q_g)
```
其中：
- `U_att(q)`: 船舶在q点位置受到目标点的奖励值
- `η`: 正比例增益系数
- `ρ(q, q_g)`: 船舶位置q和目标点位置q_g之间的欧氏距离

**全局奖励值计算（公式6）：**
```
U_att = U_att(q) + U(q),  U_att ≤ 1
```
其中：
- `U(q)`: 船舶在q点位置轨迹密度产生的奖励值
- 奖励函数数值限定在 [0, 1] 之间
- 奖励值为1 → 进入密度较高区域
- 奖励值为0 → 船舶不受高密度区域影响

##### (2) 惩罚因素函数

**障碍物惩罚函数（公式7）：**
```
U_rep(q) = { 1/(e^(1/(2×k_rep)) × (1/d(q,q_o) - 1/d_o)²),  d(q,q_o) ≤ d_o
           { 0,                                      d(q,q_o) > d_o
```
其中：
- `U_rep(q)`: 障碍物对船舶产生的惩罚值
- `k_rep`: 斥力增益系数
- `d_o`: 碍航物影响范围
- `d(q, q_o)`: 船舶到障碍物的距离

**全局惩罚值计算（公式8）：**
```
U_rep = Σ(i=1 to n) U_rep(i),  U_rep ≤ -1
```

**惩罚函数数值限定在 [-1, 0] 之间：**
- 惩罚值为 -1 → 已发生碰撞
- 惩罚值为 0 → 船舶不受碍航物影响

##### (3) 综合奖惩值函数（公式9）

```
U_all = { -1,                     U_att + U_rep ≤ -1
        { U_att + U_rep,          U_att + U_rep < 1
        { 1,                      U_att + U_rep ≥ 1
```

#### 3.2.4 优化函数参数

**改进后的实际移动成本（公式10）：**
```
g(n) = g(n-1) + C_d + Σ(i=1 to d) U_all(i)
```
其中：
- `C`: 移动一个栅格的成本
- `d`: 起始点到移动点的欧氏距离
- `U_all(i)`: 路径中第i点的奖惩值之和

**改进后的启发函数（公式11）：**
```
h(n) = C × (1 + min(U_all)) / √[(x_n-x_g)² + (y_n-y_g)²] - 1
```
其中：
- `min(U_all)`: 路径中的最小奖惩值
- `x_n, y_n`: 当前点坐标
- `x_g, y_g`: 目标点坐标

## 四、实验验证

### 4.1 实验设置
- **研究水域**: 美国安吉利斯港附近海域
- **经度范围**: [-124°0′.000, -124°35′.600]E
- **纬度范围**: [48°0′.000, 48°36′.000]N
- **船舶航行速度**: 12 nmile/h

### 4.2 参数优化结果
- 通过加权方法评估不同邻域下A*算法的表现
- 最终选择 **24个邻域节点**
- 从8邻域扩展为24邻域时，路径长度减少幅度高达 **41%**

### 4.3 对比实验结果

| 指标 | 传统A*算法 | 改进A*算法 | 改善程度 |
|------|-----------|-----------|---------|
| 最优总目标值 | 1.65 | 1.54 | ↓6.7% |
| 总目标均值 | 1.74 | 1.62 | ↓6.9% |
| 总目标值方差 | 1.373 | 1.124 | ↓18.1% |
| 平均迭代次数 | 121次 | 116次 | ↓4.1% |
| 总目标值(时间) | 2.47h | 2.30h | ↓6.9% |
| 路径长度 | 29.6704 nmile | 27.6301 nmile | ↓6.9% |
| 转向点数量 | 5个 | 1个 | ↓80% |

### 4.4 结论
- 改进A*算法在**寻优能力、稳定性和收敛速度**方面均优于传统A*算法
- 规划路径更加**平滑**，位于轨迹密度较高区域
- 更符合船舶实际航行要求

## 五、方法优势与创新点

### 5.1 创新点
1. **结合船舶轨迹密度关联特征构建水域栅格环境模型**
2. **引入奖惩函数改进A*算法**
   - 奖励机制：引导船舶向高密度（习惯航线）区域航行
   - 惩罚机制：驱离船舶避开碍航物
3. **扩展节点至24邻域**，提升路径平滑性

### 5.2 方法优势
- 收敛速度更快
- 路径长度更短
- 转向点更少（减少80%）
- 运行时间更短
- 规划路径符合实际船舶航行习惯

## 六、局限性与未来工作

### 6.1 局限性
- 主要关注不同轨迹密度下的交通状况
- 未充分考虑恶劣自然环境因素（如风、流、浪等）

### 6.2 未来研究方向
- 深入探讨自然环境因素对路径规划的影响
- 进一步提高船舶路径规划方法的全面性和适用性
