## 一、研究背景与问题

### 1.1 研究背景
- **几何航路网络**是航路网络几何边界信息的外在表现
- 反映了船舶航行的可航水域
- 能够实现船舶智能航行时的**自动偏航检测**
- 保障船舶航行安全

### 1.2 核心问题
1. **海上航路边界模糊**: 海上航路的边界常常是模糊的和难以确定的，无法通过传统遥感影像方法构建几何航路网络
2. **现有方法的局限性**:
   - **节点-边模型方法**（如TREAD、网格化方法）：只提取了拓扑信息，**缺失了几何信息**
   - **边界提取方法**（如三角剖分、alpha-shape）：提取了可航水域几何信息，但**缺失节点连接关系**

### 1.3 解决思路
通过数据挖掘手段从海量船舶轨迹数据中提取几何航路网络：
- ✅ 既包含**拓扑结构**（节点连接关系）
- ✅ 又包含**几何信息**（实际边界）

## 三、核心术语定义

| 术语 | 定义 | 说明 |
|------|------|------|
| **单船轨迹点** | 某一时刻单艘船舶航行的空间位置，包含航速、航向等属性 | 基本数据单元 |
| **单船轨迹特征点** | 船舶发生特殊行为时的轨迹点（停留、转向、边界） | 关键行为识别 |
| **停留特征点** | 船舶在港口停泊、锚地锚泊等发生停留行为的轨迹点（船速低或为零） | 速度=0 |
| **转向特征点** | 船舶发生转向行为的轨迹点（航向变化明显） | 需要计算航向差和变化率 |
| **边界特征点** | 船舶出入研究水域时与水域边界相交的轨迹点（首尾点） | AIS数据按区域分割存储 |
| **航路点聚簇** | 多艘船舶轨迹特征点经密度聚类后去掉噪声点的簇 | DBSCAN结果 |
| **航路点区域** | 多数船舶发生特殊行为时的多边形区域 | 凸包计算结果 |
| **航路** | 连接航路点区域的多边形区域，具有实际边界属性 | Alpha-Shape提取 |

### 4.2 第一阶段：航路点区域提取

#### 4.2.1 船舶轨迹特征点识别

##### (1) 停留特征点识别
**规则**: `speed = 0`
- 将速度为零的轨迹点识别为停留特征点
- 代表：港口停泊、锚地锚泊等行为

##### (2) 边界特征点识别
**规则**: 每条轨迹的起止点
- 由于AIS数据按照区域分割后存储
- 每条轨迹的第一个点和最后一个点即为边界特征点

##### (3) 转向特征点识别 ⭐（核心创新）

**问题**: 
- 无法通过简单的航向属性进行识别
- 船舶存在缓慢转向情况，前后轨迹点航向变化不明显

**解决方案**: 结合**航向差**和**航向变化率**双重指标

**数学表达**:

假设单艘船舶的轨迹数据为：
$$traj = (p_1, p_2, ..., p_n)$$

其中每个轨迹点 $p_i = (t_i, lon_i, lat_i, cog_i, sog_i)$

**步骤1: 计算航向变化绝对值 α**
$$\alpha_i = |cog_{t_{i+1}} - cog_{t_i}| \quad \text{(公式1)}$$

**步骤2: 计算航向变化率 β**
$$\beta_i = \left|\frac{cog_{t_{i+1}} - cog_{t_i}}{t_{i+1} - t_i}\right| \quad \text{(公式2)}$$

**步骤3: 转向特征点判定条件**
$$
\begin{cases}
sog > 0 \\
\alpha > \mu \quad (\text{转向阈值}) \\
\beta > \upsilon \quad (\text{转向速率阈值})
\end{cases}
\quad \text{(公式3)}
$$

**参数说明**:
- $\mu$: 转向特征点转向阈值（需根据实际情况设定）
- $\upsilon$: 转向速率阈值（需根据实际情况设定）
- $sog > 0$: 排除静止状态

#### 4.2.2 航路点聚类及航路点区域生成

##### (1) DBSCAN密度聚类

**选择理由**: 
- 在停泊、转向以及进出边界等区域的船舶轨迹点通常较为密集
- DBSCAN能够将足够高密度的轨迹点划分成簇
- 能够有效识别并去除噪声点

**输入**: 所有船舶的轨迹特征点集合  
**输出**: 航路点聚簇集合

##### (2) 凸包算法计算航路点区域

**算法**: Convex Hull Algorithm（凸包算法）

**过程**:
```
对每个航路点聚类簇:
    → 计算凸多边形（Convex Polygon）
    → 凸多边形包含的水域即为航路点区域
```

**实验结果**: 
- 提取得到 **25个航路点聚类簇**
- 生成 **25个航路点区域**

---

### 4.3 第二阶段：航路点区域连接

#### 4.3.1 航路点区域连接关系矩阵构建

**核心思想**: 利用船舶航行轨迹保留的连接关系

**方法**: 空间关系计算

**具体步骤**:

##### 步骤1: 轨迹点标记
当船舶轨迹经过不同航路点区域时：
- 将处于航路点区域内部的轨迹点进行标记（标记为区域ID）
- 同时记录该轨迹点在原轨迹序列中的索引位置

**示例**:
```
原始轨迹: [p1, p2, p3, p4, p5, p6, ...]
                    ↓
标记后:    [1, 1, 2, 2, 2, 3, ...]
(数字表示所属的航路点区域ID)
```

##### 步骤2: 生成航路点区域序列
从标记后的轨迹中提取航路点区域序列：

**示例**:
```
单船轨迹经过6次共5个航路点区域:
wp_seq = [1, 2, 3, 4, 5, 4]

相邻区域对（连通关系）:
(1,2), (2,3), (3,4), (4,5), (5,4)
```

##### 步骤3: 构建连接关系矩阵
- 将所有连通的区域对存入矩阵
- 矩阵元素 $D[i][j]$ 表示区域i到区域j的轨迹数量
- 构建**双层航路网络节点连接关系矩阵**

**矩阵特点**:
- **双层**: 区分方向（i→j 和 j→i 分别统计）
- **加权**: 元素值为轨迹数量（反映交通流量）

#### 4.3.2 航路生成方法 ⭐（核心创新）

##### 步骤1: 子轨迹提取
利用之前记录的索引位置，提取航路点区域间的子轨迹：

```
完整轨迹: [..., 区域A的点, ..., 区域B的点, ...]
                              ↓
                   提取子轨迹: [区域A的最后一点, ..., 区域B的第一点]
```

##### 步骤2: 改进的轨迹相似性度量

**传统豪斯多夫距离（Hausdorff Distance）**:

对于两条轨迹 $A = \{a_1, ..., a_m\}$ 与 $B = \{b_1, ..., b_n\}$:

**单向豪斯多夫距离**:
$$h(A,B) = \max_{a \in A} \{\min_{b \in B} |a - b|\} \quad \text{(公式5)}$$

$$h(B,A) = \max_{b \in B} \{\min_{a \in A} |b - a|\} \quad \text{(公式6)}$$

**双向豪斯多夫距离**:
$$H(A,B) = \max(h(A,B), h(B,A)) \quad \text{(公式4)}$$

**含义**: 度量两条轨迹间的最大不匹配程度，距离越小越相似

**⭐ 创新改进: 引入方向因子**

**问题**: 传统豪斯多夫距离未考虑轨迹方向

**解决方案**: 用航路点区域间的向量表示子轨迹方向

**方向定义**:
$$C = \begin{cases}
1 & \overrightarrow{AB} \quad (\text{从区域A到区域B}) \\
-1 & \overrightarrow{BA} \quad (\text{从区域B到区域A})
\end{cases} \quad \text{(公式8)}$$

**方向差 ΔC**:
- 同向时: $ΔC = 2$ 或 $-2$
- 反向时: $ΔC = 0$

**改进的轨迹相似性度量**:
$$\eta = \begin{cases}
+\infty & ΔC = 0 \quad (\text{反向，不应聚为一类}) \\
H(A,B) & ΔC = ±2 \quad (\text{同向，用豪斯多夫距离})
\end{cases} \quad \text{(公式9)}$$

**优势**:
- ✅ 反向轨迹相似性设为无穷大，强制分离
- ✅ 同向轨迹基于实际空间距离聚类
- ✅ 符合航海实际（往返航线应区分）

##### 步骤3: DBSCAN子轨迹聚类

**输入**: 航路点区域间的所有子轨迹  
**距离度量**: 改进的轨迹相似性 η  
**算法**: DBSCAN  
**输出**: 多个轨迹簇（每个簇代表一条主要航路模式）

##### 步骤4: Alpha-Shape边界提取

**为什么不用凸包?**
- 凸包算法在凹边形上效果不好
- 实际航路可能呈现不规则形状（受岛屿、浅滩等影响）

**Alpha-Shape算法原理**:

```
输入: 轨迹簇散点集, 参数alpha
输出: 边界多边形（航路）

步骤:
1. 遍历轨迹簇，获取散点集
2. 以alpha为半径做过任意两点p1, p2的圆
3. 判断: 如果圆内不包含第三个点 → p1, p2是边界点
4. 重复步骤2-3，提取所有边界点
5. 连接边界点形成航路边界线
```

**参数 alpha 的含义**:
- 控制边界的精细程度
- alpha越大，边界越平滑（趋向凸包）
- alpha越小，边界越精细（贴合实际分布）

**实验结果示例**:
- 9号 ↔ 10号航路点区域之间
- 黄色轨迹: 9→10方向的航路
- 绿色轨迹: 10→9方向的航路
- 成功提取出两个方向的独立航路

### 4.4 第三阶段：几何航路网络生成

#### 4.4.1 连接阈值设定

**定义**: 决定各航路点区域是否连通的最小轨迹数量

**作用**:
- 过滤掉偶然的、非典型的航行路径
- 保证网络的代表性和可靠性

**本文设定**: **φ = 5**

**判定规则**:
```
if D[i][j] ≥ 5:
    有效连通（正常航行的航路）
else:
    无效连通（偶发或异常路径）
```

**合理性分析**:
- 轨迹数量 < 5: 难以提取有价值的航路信息
- 轨迹数量 ≥ 5: 表明该航路被船舶频繁使用，具有代表性

#### 4.4.2 网络构建算法

**输入**: 
- 航路点区域集合（25个）
- 连接关系矩阵 D
- 各区域间的航路集合
- 连接阈值 φ = 5

**算法流程**:

```
步骤1: 遍历连接矩阵D
    for each D[i][j]:
        if D[i][j] ≥ φ:
            标记(i,j)为有效连通
        else:
            标记(i,j)为无效连通

步骤2: 对于每个有效连通对(i,j):
    提取对应的航路R_ij
    计算航路与两个航路点区域的交集
    连接航路点区域i和j

步骤3: 重复步骤2直到所有有效连通处理完毕

输出: 几何航路网络G = (V, E)
      V: 航路点区域（节点）
      E: 航路（带几何边界的边）
```

**网络特性**:
- ✅ **有向性**: 区分往返方向的不同航路
- ✅ **几何性**: 边具有实际的多边形边界
- ✅ **层次性**: 双层连接矩阵支持多层次分析

### 9.1 局限性

| 局限 | 说明 | 影响 |
|------|------|------|
| **参数敏感性** | DBSCAN的ε和MinPts、Alpha-Shape的alpha需人工调优 | 不同水域需要重新调参 |
| **计算复杂度** | 豪斯多夫距离计算O(mn)，大数据量时效率较低 | 不适合实时处理 |
| **特征点依赖** | 仅基于三种特征点（停、转、边界），可能遗漏其他重要区域 | 网络覆盖可能不全 |
| **时间静态性** | 构建的网络是某一时期的快照，未考虑时变性 | 无法反映季节性变化 |
| **阈值主观性** | 连接阈值φ=5为主观设定，缺乏理论依据 | 可能影响网络完整性 |

### 9.2 未来改进方向

1. **🤖 参数自适应**: 开发自适应参数选择机制
2. **⚡ 算法优化**: 采用近似算法加速豪斯多夫距离计算
3. **📈 特征扩展**: 引入更多船舶行为特征（变速、会遇等）
4. **⏰ 时序建模**: 构建动态几何航路网络，捕捉时变规律
5. **🧮 阈值优化**: 基于统计学习或领域知识确定最优连接阈值
6. **🌊 多源融合**: 结合水文、气象数据增强网络表达能力

## 十一、核心公式汇总

| 编号 | 公式名称 | 数学表达式 | 用途 |
|------|----------|------------|------|
| (1) | 航向变化绝对值 | $\alpha_i = \|cog_{t_{i+1}} - cog_{t_i}\|$ | 转向特征点识别 |
| (2) | 航向变化率 | $\beta_i = \left\|\frac{cog_{t_{i+1}} - cog_{t_i}}{t_{i+1} - t_i}\right\|$ | 转向速率计算 |
| (3) | 转向判定条件 | $sog>0 \land \alpha>\mu \land \beta>\upsilon$ | 特征点筛选 |
| (4) | 双向豪斯多夫距离 | $H(A,B) = \max(h(A,B), h(B,A))$ | 轨迹相似性基础 |
| (5) | 单向豪斯多夫距离(AB) | $h(A,B) = \max_{a\in A}\{\min_{b\in B}\|a-b\|\}$ | 点集距离度量 |
| (6) | 单向豪斯多夫距离(BA) | $h(B,A) = \max_{b\in B}\{\min_{a\in A}\|b-a\|\}$ | 点集距离度量 |
| (8) | 轨迹方向向量 | $C = \begin{cases}1(\overrightarrow{AB})\\-1(\overrightarrow{BA})\end{cases}$ | 方向编码 |
| (9) | 改进相似性度量 | $\eta=\begin{cases}+\infty&(\Delta C=0)\\H(A,B)&(\Delta C=±2)\end{cases}$ | 方向感知聚类 |

## 附录：方法应用建议

### 适用场景清单
- ✅ 港口及附近水域
- ✅ 沿海主航道
- ✅ 狭水道（海峡、河口等）
- ✅ 锚地及周边区域
- ⚠️ 大洋航线（轨迹稀疏，效果有限）
- ❌ 内河限制水域（需额外考虑桥梁、船闸等约束）

### 实施建议
1. **数据准备**: 至少3-6个月的连续AIS数据
2. **参数调优**: 先在小范围测试确定最优参数
3. **质量验证**: 与当地海图、航海经验比对验证
4. **定期更新**: 建议3-6个月更新一次网络
5. **系统集成**: 输出标准格式（GeoJSON/S-57），便于集成到现有系统
