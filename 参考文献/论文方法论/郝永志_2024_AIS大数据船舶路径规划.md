### 二、模块1: 基于改进Sliding Window的AIS轨迹特征提取

#### 2.1 AIS数据预处理（4步清洗流程）

| 步骤 | 方法 | 目标 |
|------|------|------|
| 重复数据去除 | SNM排序邻域法 | 消除AIS重复报文 |
| 错误数据检测 | 速度/位置阈值 | 删除漂移点 |
| 缺失数据检测 | 时间间隔阈值 | 识别信号中断 |
| 缺失数据补全 | 多项式插值法 | 补全缺失轨迹段 |

**SNM算法关键逻辑**:
1. 按时间戳排序AIS数据
2. 相邻记录时间差 > 阈值 → 正常存入
3. 时间差 < 阈值 → 视为重复数据剔除

#### 2.2 改进Sliding Window算法（核心创新①）
**经典SW局限**: 固定窗口大小，无法适应船舶不同行为阶段
**改进方案**:

| 改进点 | 具体内容 |
|--------|---------|
| 转向角阈值参数 | 引入自适应转向角判断 |
| 窗口指针移动方式 | 根据转向行为动态调整 |
| 距离隔离值 | 为每条船设定独立阈值 |
| 角度阈值确定 | 通过AIS大数据统计自动计算 |

**效果验证**: 
- 特征点保留船舶行为转向点
- 能较好还原船舶转向渐变过程
- 提高运算效率

### 三、模块2: 基于改进DBSCAN的AIS数据聚类

#### 3.1 为什么需要改进DBSCAN?
- 不同类型船舶（渔船/客船/货船/油轮）混在一起
- DBSCAN的eps和MinPts需人工设定 → 效果不稳定

#### 3.2 改进策略（核心创新②）

| 改进维度 | 方法 |
|---------|------|
| 船舶分类 | 引入**随机森林**分类器，先按船型预分类 |
| eps参数 | 引入**萤火虫算法(FA)**自适应寻优 |
| MinPts参数 | 同上FA算法联合优化 |

**萤火虫算法(FA)伪代码**:

#### 3.3 实验结果（舟山北部水域）

| 船型 | 分类准确率 |
|------|-----------|
| 渔船 | 90.6% |
| 客船 | 94.2% |
| 货船 | 91.5% |
| 油轮 | 88.7% |

**评价指标**: Accuracy, F-measure, RI, ARI, MI, AMI, NMI（7个指标全面优于传统DBSCAN）

### 四、模块3: 构建航路有向网

#### 4.1 连通性识别
**问题**: 聚类得到的转向点可能属于不同船舶的不同航路
**解决方案**: 提出9种规则判断两转向点是否连通

**WPT (Way Point) 数据结构**:
```
WPT = {λ, φ, TUR, MMSI, C_in, C_out}
```
- λ, φ: 经纬度
- TUR: 转向角
- MMSI: 船舶识别码
- C_in: 入航向
- C_out: 出航向

**连通性判定规则**:
1. 两转向点至少各有1个轨迹点属同船同轨迹
2. 两转向点能否直接连接（距离/角度约束）
3. 同MMSI分组 → 找最近转向点 → 判定连通

#### 4.2 航路有向网输出
- 节点: 转向点 (Way Points)
- 有向边: 从C_in到C_out的可行航路
- 权重: 基于历史AIS统计的平均通行属性

### 五、模块4: 基于SMQPSOA的船舶路径规划（核心创新③）

#### 5.1 为什么需要新算法?

| 算法 | 优点 | 缺点 |
|------|------|------|
| 藁菌算法(SOA) | 寻优能力强 | 系统性不强、后期易震荡 |
| 粒子群算法(PSO) | 控制参数少、收敛快 | 易陷入局部最优 |

#### 5.2 SMQPSOA算法设计（藁菌-量子粒子群融合）

**融合思路**:
```
SOA筛选优质航段 → 航段两端固定 → PSO定向选择 → 减少路径点访问量 → 降低计算复杂度
```

**关键改进**:
1. 利用SOA筛选**优质航段**（而非单点）
2. 将航段的**两端点固定**为PSO的定向选择目标
3. 减少**路径点的访问数量**
4. 降低**计算复杂度**
5. 提高**搜索效率**
6. 增强**鲁棒性**（减少波动性）

#### 5.3 仿真结果对比

| 指标 | SMQPSOA | A* | 其他算法 |
|------|---------|----|---------|
| 路径长度 | 最短/次短 | - | - |
| 平均路径长度 | 均优于两种算法 | - | - |
| 路径长度标准差 | 明显提高 | - | - |
| 平均λ交叉因子 | 明显提高 | - | - |
| 收敛迭代数 | 明显减少 | - | - |
| 局部最优规避 | 有效避免 | 可能陷入 | - |

#### 5.4 实际案例验证
- **遮蔽水域** + **开阔水域** 两个场景
- 不同船舶航行任务
- 结果: 能有效避开碍航物、满足吃水要求、符合主管机关约束、满足国际避碰规则、遵从交通流和习惯航法
