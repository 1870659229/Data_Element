## 一、研究背景与问题

### 1.1 研究背景

**数据基础**:
- **AIS (船舶自动识别系统)**: 获取舰船航行位置、航速、航向、环境变化等动态信息
- 形成海量时空数据，支撑船舶避碰、航线规划等基础功能
- 隐含着舰船行为模式、交通流特征及潜在安全风险

**问题根源**:
| 因素 | 导致的异常类型 |
|------|----------------|
| 复杂多变的海洋环境 | 数据波动、信号干扰 |
| 设备故障 | 数据缺失、传输中断 |
| 人为操作失误 | 轨迹偏离、参数错误 |
| 数据传输干扰 | 数据丢包、时序错乱 |

**异常数据的危害**:
- ❌ 干扰船舶监控系统的正常运行
- ❌ 误导决策，对航行安全构成严重威胁
- ❌ 影响航行轨迹控制精度
- ❌ 增加航行过程中的不安全因素

### 1.2 核心挑战

**数据特性**:
1. **高维度**: 包含位置、速度、航向、时间、环境等多维信息
2. **多模态**: 连续值（位置、速度）、离散值（状态码）、类别值（船型）混合
3. **强动态**: 实时更新、分布随时间和环境变化

**识别难点**:
1. ⚠️ **异常与正常难以区分**: 异常数据与正常航行数据的区分难度增加
2. ⚠️ **停留数据干扰**: 停留数据呈现聚集状态，与密集分布的异常数据相似
3. ⚠️ **多类型异常混杂**: 缺失、离散、破损等多种异常形式共存

### 1.3 现有方法的局限性

| 方法 | 局限性 |
|------|--------|
| **滑动窗口法** (陈蜀喆等) | 窗口大小和步长需预先设定；不同航速、海况下最优参数不同；对数据动态变化的适应能力较差 |
| **Hausdorff+DBSCAN** (祁文娟等) | 分段策略依赖空间几何信息，忽略时空动态特性（速度变化、时间间隔）；分段精度不足 |
| **改进LSTM** (李费旭等) | 船舶运行环境变化导致数据分布偏移，模型检测结果可靠性下降 |
| **多源传感器+机器学习** (黄滔等) | 对空间数据的检测效果较差；空间动态变化时无法可靠判断数据类别 |

### 1.4 解决思路

**采用聚类分析方法**:
- ✅ 无监督学习核心手段
- ✅ 处理复杂数据时展现强大适应性和灵活性
- ✅ 能够适应动态变化的航行环境
- ✅ 特别适用于**数据分布复杂、异常模式多样**的场景

### 2.2 核心创新：全局-局部融合机制 ⭐

**设计理念**:
- **全局视角**: 捕捉整体分布中的离群点（稀疏异常）
- **局部视角**: 识别局部密度异常（密集异常）
- **融合机制**: 综合两个视角，避免单一视角的盲区

## 三、核心方法详解

### 3.1 数据定义与表示

#### 3.1.1 航行轨迹数据结构

假设舰船的航行轨迹为 $X_l$：

$$X_l = \{x_1^l, x_2^l, ..., x_j^l, ..., x_n^l\} \quad \text{(公式1)}$$

其中第 $j$ 个轨迹点数据为：

$$x_j^l = <\lambda_j^l, \varphi_j^l, t_j^l, \vartheta_j^l>$$

| 符号 | 含义 | 类型 |
|------|------|------|
| $\lambda_j^l$ | 经度 | 连续值 |
| $\varphi_j^l$ | 纬度 | 连续值 |
| $t_j^l$ | 时间戳 | 时间值 |
| $\vartheta_j^l$ | 方向/航向 | 角度值 |
| $n$ | 数据量 | 整数 |

#### 3.1.2 异常数据分类体系

本文将异常数据分为三类：

| 类别 | 定义 | 典型表现 | 成因 |
|------|------|----------|------|
| **缺失数据** | 轨迹点序列不连续，部分数据记录完全丢失 | 时间跳跃、空间断裂 | 设备故障、信号中断 |
| **离散数据** | 明显偏离正常航行模式的孤立或少量轨迹点 | 远离主轨迹的离群点 | 临时性干扰、人为错误、突发状况 |
| **破损数据** | 数据记录存在但数值异常或格式错误 | 经纬度超范围、航速为负、时间戳错乱 | 传感器故障、传输错误 |

### 3.2 第一阶段：基于聚类分析的数据异常得分计算

#### 3.2.1 全局离散异常值计算 ⭐

**算法**: K近邻聚类分析 (K-Nearest Neighbors, KNN)

**核心思想**:
- 如果数据点呈**密集分布** → 各点间距离小 → k近邻距离小 → 正常
- 如果数据点呈**稀疏分散分布** → 各点间距离大 → k近邻距离大 → **异常**

**数学表达**:

对于航行数据点 $x_i$，其全局离散异常值为：

$$q(x_i) = \sum_{k=1}^{n} d_k(x_i, x_j) \quad \text{(公式2)}$$

其中：
- $d_k(x_i, x_j)$: 数据点 $x_i$ 和 $x_j$ 之间的**k近邻距离**
- $n$: 近邻数量

**判定规则**:
$$q(x_i) \uparrow \Rightarrow \text{异常概率} \uparrow$$

**适用场景**:
- ✅ 检测**稀疏分散**的异常数据
- ✅ 捕捉**全局视角**下的离群点
- ❌ 对**密集分布**的异常数据不敏感

#### 3.2.2 局部离散异常值计算 ⭐

**算法**: 密度峰值聚类 (Density Peak Clustering, DPC)

**选择原因**:
- 全局离散异常值 $q(x_i)$ 无法准确判断**密集分布**的异常情况
- 密度峰值聚类可充分考虑数据**局部的密度情况**
- 能够区分"正常的高密度区域"和"异常的高密度聚集"

**数学表达**:

##### 步骤1: 计算簇的平均密度 $\bar{\rho}_c$

结合数据点 $x_i$ 和 $x_j$ 之间的近邻距离 $d_k(x_i, x_j)$ 进行聚类后，计算各个类别簇 $c$ 的平均密度：

$$\bar{\rho}_c = \frac{1}{k|N_c|} \sum_{k=1}^{n} \frac{1}{(2\pi)^{\tau}} \times \exp\left(-\frac{d_k(x_i, x_j)^2}{2}\right) \quad \text{(公式3)}$$

其中：
- $c$: 簇标识
- $N_c$: 该簇的数据量
- $\tau$: 维度（数据维度）
- 公式形式: **高斯核密度估计**

##### 步骤2: 计算局部离散异常值 $\sim q(x_i)$

$$\sim q(x_i) = \frac{\bar{\rho}_c}{\rho_{x_i}} \quad \text{(公式4)}$$

其中：
- $\bar{\rho}_c$: 数据点 $x_i$ 所在簇的平均密度
- $\rho_{x_i}$: 数据点 $x_i$ 所在簇的**核密度**

**物理含义**:
- 若 $\rho_{x_i}$ 远小于 $\bar{\rho}_c$ → 点所在局部区域密度显著低于簇平均 → **局部异常**
- 若 $\rho_{x_i}$ 接近 $\bar{\rho}_c$ → 点符合簇内正常分布 → **正常**

**适用场景**:
- ✅ 检测**密集分布**中的异常数据
- ✅ 区分"正常停留数据"和"异常聚集数据"
- ✍️ 补充全局视角的不足

#### 3.2.3 综合异常得分计算 ⭐⭐（核心创新）

**融合策略**: 乘法融合

$$\hat{q} = q(x_i) \times \sim q(x_i) \quad \text{(公式5)}$$

**为什么用乘法而非加法？**

| 融合方式 | 特点 | 问题 |
|----------|------|------|
| 加法 $q + \sim q$ | 简单线性组合 | 可能被单一高值主导 |
| **乘法 $q \times \sim q$** | **非线性增强** | **✅ 双重条件都高才真正异常** |

**乘法融合的优势**:
1. 🎯 **双重验证**: 只有在全局和局部都表现为异常时，综合得分才高
2. 🔒 **降低误判**: 单一视角的假阳性被抑制
3. ⚡ **放大真阳性**: 真正的异常数据在两个维度上都表现异常，得分被放大

**异常判定规则**:
$$\hat{q}(x_i) > \text{阈值} \Rightarrow x_i \text{ 为异常数据}$$

**输出**: 选择异常得分值最高的 **Top-m** 个数据点作为异常数据集合 $\sim YM$

### 3.3 第二阶段：基于最小熵K-均值的异常数据分类

#### 3.3.1 为什么需要分类？

检测出异常数据后，还需要回答：
- 这是哪种类型的异常？（缺失？离散？破损？）
- 不同类型的异常需要不同的处理策略

**传统K-均值的问题**:
- ❌ 需要预先指定聚类数 $K$
- ❌ 对于异常数据这种未知分布的数据，$K$ 难以确定
- ❌ 固定 $K$ 可能导致欠聚类或过聚类

**解决方案**: 最小熵K-均值算法

#### 3.3.2 最小熵K-均值算法详解 ⭐

**核心思想**: 通过**信息熵最小化**自适应确定最佳聚类数 $K$

**信息熵的含义**:
- 熵越低 → 聚类结果越纯（同一类别的数据越相似）
- 熵越高 → 聚类结果越混乱（不同类别的数据混在一起）

**算法流程**:

##### 步骤1: 初始化聚类中心
在异常数据集 $\sim YM$ 中随机抽取 $K$ 个数据作为初始聚类中心：
$$O_K = \{o_1, o_2, ..., o_K\}$$

##### 步骤2: 初次分配
依据**欧式距离**大小将所有 $\sim YM$ 划分至最近的聚类中心对应的类别中，形成各个子类别。

##### 步骤3: 更新聚类中心
计算各子类别中数据样本的均值 $\bar{y}_m$，以此获取该类别新的聚类中心：

$$o_K = \frac{1}{M_k} \sum_{m=1}^{M_k} \bar{y}_m \quad \text{(公式6)}$$

其中：
- $M_k$: 第 $k$ 个子区域中异常数据量
- $\bar{y}_m$: 第 $m$ 个样本的均值向量

##### 步骤4: 重新分配
对所有数据样本进行重新聚类，依据欧式距离大小将其划分至最近的聚类中心对应的类别中。

##### 步骤5: 计算聚类信息熵 ⭐（关键步骤）

$$\kappa_m = -\frac{1}{M_k} \sum_{m=1}^{M_k} p_m \log(p_m) \quad \text{(公式7)}$$

其中：
- $p_m$: 第 $m$ 类在第 $k$ 个聚类簇中所占的比例
- $\kappa_m$: 第 $k$ 个聚类的信息熵

**熵的解释**:
- $\kappa_m \to 0$: 聚类非常纯，各类别分离清晰
- $\kappa_m \uparrow$: 聚类混乱，类别边界模糊

##### 步骤6: 迭代优化
重复步骤2-5，当满足停止条件时终止：
- 停止条件: **聚类数量与聚类样本数一致后停止**
- 选择准则: 将**最小信息熵结果**作为最优聚类结果

**最终输出**: 
- 最佳聚类数 $K_{optimal}$
- 各异常数据点的类别标签（缺失/离散/破损）

## 四、实验设计与结果分析

### 4.1 实验对象

| 参数 | 数值 |
|------|------|
| 船型 | 大型货船 |
| 船长 | 366 m |
| 垂线间长 | 350 m |
| 船宽 | 51 m |
| 型深 | 30.20 m |
| 设计吃水 | 14.50 m |
| 航速 | 22 kn |
| 主要航行路线 | 3条 |
| 中转航行路线 | 4条 |

### 4.2 实验场景

选取**出发点和目标点1之间**的航行数据进行测试

### 4.3 评价指标

**标准化互信息 NMI (Normalized Mutual Information)**:

$$\mu(y,c) = \frac{I(y,c)}{\frac{1}{2}[\eta(y) + \eta(c)]} \quad \text{(公式8)}$$

其中：
- $y$: 异常数据类别实际标签
- $c$: 方法分类标签
- $I(\*)$: 互信息度量
- $\eta(\*)$: 熵

**取值范围**: [0, 1]
- $\mu(y,c) \to 1$: 分类结果与真实标签高度一致
- $\mu(y,c) \to 0$: 分类结果接近随机猜测

### 4.4 实验结果

#### 4.4.1 异常得分分布特征

**整体趋势**:
- ✅ 绝大多数数据点的异常得分较低（<0.2），属于正常航行或停留模式
- ⚠️ 少数数据点异常得分显著偏高（最高接近0.8），形成明显峰值
- 📊 异常数据点呈**离散分布**，得分极高但数量稀少
- 🔄 部分异常数据之间存在关联覆盖，在空间上呈聚集状态

**关键发现**:
> 本文方法通过局部离散异常值的计算，仍能有效区分各异常数据的异常值，具备良好的**异常-正常/停留数据分离性**

#### 4.4.2 聚类信息熵分析

**测试对象**: 异常密集数据 vs 异常离散数据

**结果特征**:
1. **整体趋势**: 两种数据的聚类信息熵均呈相对平稳波动趋势，未出现剧烈上升或下降
2. **数值水平**: 信息熵结果均**低于0.12**，表明聚类效果良好
3. **稳定性**: 当数据量>1400条后波动较明显，但仍能可靠完成两类异常数据的划分

**结论**: 
> 本文方法能够更精准地完成不同规模异常数据类别划分

#### 4.4.3 多类别异常识别性能 ⭐⭐

**测试规模**: 2万条 ~ 16万条数据

**标准化互信息 (NMI) 结果**:

| 数据量(万条) | 缺失数据 | 离散数据 | 破损数据 |
|-------------|---------|---------|---------|
| 2 | **0.944** | **0.962** | **0.955** |
| 4 | **0.938** | **0.958** | **0.951** |
| 6 | **0.942** | **0.955** | **0.949** |
| 8 | **0.951** | **0.953** | **0.956** |
| 10 | **0.946** | **0.961** | **0.954** |
| 12 | **0.949** | **0.954** | **0.952** |
| 14 | **0.941** | **0.956** | **0.955** |
| 16 | **0.943** | **0.963** | **0.953** |

**关键发现**:
1. 🎯 **高性能**: 所有情况下NMI均**高于0.938**（优秀水平）
2. 📈 **稳定性**: 即使在16万条大规模数据下，NMI仍保持在0.943~0.963
3. ⚡ **无性能衰减**: 未因数据量增大而出现性能下降
4. 🏆 **最佳类别**: 离散数据识别效果最好（最高0.963）

**工程意义**:
> 本方法适用于实际航行中的**海量AIS数据处理**，在多类别异常识别任务中的有效性高

### 7.1 与现有方法对比

### 7.2 核心优势总结

1. **🎯 双视角融合**: 同时考虑全局稀疏和局部密度异常，避免漏检
2. **🔄 自适应性强**: 无需人工调参（除基本阈值外），适应动态环境
3. **📊 多维度输出**: 不仅检测异常，还分类异常类型，指导后续处理
4. **⚡ 高效稳定**: 大规模数据下性能不衰减，适合工程应用
5. **🔓 无监督学习**: 不依赖标注数据，降低应用门槛

## 八、局限性与未来工作

### 8.1 当前局限性

| 局限 | 说明 | 影响 |
|------|------|------|
| **参数依赖** | KNN的k值、DPC的截断距离dc仍需经验设定 | 不同数据集可能需要调整 |
| **计算复杂度** | KNN的全局距离计算 O(n²)，大数据量时效率受限 | 不适合实时流式处理（当前版本） |
| **阈值主观性** | Top-m的选择、异常得分的判定阈值缺乏理论依据 | 可能影响召回率/精确率平衡 |
| **单源数据** | 仅使用AIS数据，未融合其他传感器信息 | 对某些复杂异常可能漏检 |
| **离线处理** | 当前实现为批处理模式，非实时在线检测 | 时延较高，不适合即时预警 |

### 伪代码框架

```python
# ===== 第一阶段：异常得分计算 =====

# Step 1: 全局异常值 (KNN)
def compute_global_anomaly(X, k=10):
    # 计算每个点到其k个最近邻的距离总和
    knn = NearestNeighbors(n_neighbors=k)
    knn.fit(X)
    distances, _ = knn.kneighbors(X)
    q_xi = np.sum(distances, axis=1)  # 公式2
    return q_xi

# Step 2: 局部异常值 (DPC)
def compute_local_anomaly(X, dc):
    # 密度峰值聚类 + 核密度估计
    clusters = density_peak_clustering(X, dc)
    rho_c = compute_cluster_density(clusters)  # 公式3
    rho_xi = compute_point_density(X, clusters)
    q_tilde_xi = rho_c / rho_xi  # 公式4
    return q_tilde_xi

# Step 3: 综合异常得分
q_hat = q_xi * q_tilde_xi  # 公式5 (乘法融合)

# Step 4: 选择Top-m异常数据
anomaly_indices = np.argsort(q_hat)[-top_m:]  # ～YM
anomaly_data = X[anomaly_indices]

# ===== 第二阶段：异常数据分类 =====

# Step 5-6: 最小熵K-均值
best_k, best_labels, min_entropy = minimum_entropy_kmeans(
    anomaly_data, max_k=10
)

# 输出结果
output = {
    'anomaly_scores': q_hat,
    'anomaly_data': anomaly_data,
    'category_labels': best_labels,  # 0:缺失, 1:离散, 2:破损
    'optimal_k': best_k,
    'entropy': min_entropy
}
```
